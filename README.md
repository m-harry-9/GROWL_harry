# GROWL Onboarding

A collection of my work and learning from the **GROWL Task Force onboarding process**, documenting my progress in gravitational-wave astronomy, binary black hole research, and computational astrophysics.

## About


This repository contains the exercises, code, analyses, and notes developed during my onboarding with the GROWL Task Force.

The work focuses on understanding and analysing topics related to:

- Binary stellar evolution
- Compact-object formation
- Binary black hole systems
- Gravitational-wave astrophysics
- Population synthesis
- Computational and data-driven analysis

The notebooks document my progression through the onboarding modules, including the implementation of concepts, analysis of simulated data, and exploration of the underlying physical models.
